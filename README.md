# Standalone CrossPoint Font Builder

A completely browser-side font converter to generate `.cpfont` files for [CrossPoint reader](https://github.com/crosspoint-reader/crosspoint-reader). Available at https://brianhuster.github.io/cpfont-builder/

## Local Development / Testing
Simply run a local static server inside this directory:
```bash
npx serve .
# or
python3 -m http.server
```
And navigate to `http://localhost:8000` (or the port specified by serve).
